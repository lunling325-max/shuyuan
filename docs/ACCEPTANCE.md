> **版本提醒（2026-11-14 已重新部署）**：线上跑的是最新版。**10 步里线上验过 9 步**

## 0. 打开页面（10 秒）

页面顶部是 11 个视图：文献库 / 阅读器 / 版本谱系 / 中英对照 / 跨文献对比 / 引用图谱 /
文献检索 / 每日推荐 / 学术综述 / 任务 Agent / 写作 Copilot。

**应该看到**：文献库列表是满的（线上 15 篇），每行标题下有作者与机构。
**看不到**：列表为空 → 库没灌（`uv run python scripts/seed_demo.py`）；
显示"连不上后端" → 服务没起来，先看 `/api/health`。

**动手前先跑这一条**（10 秒，比点十下都值）：

```
uv run python ../../scripts/check_testcases.py                 # 查线上
uv run python ../../scripts/check_testcases.py --server http://127.0.0.1:8017   # 查本地
```

## 1. 问答 + 溯源（90 秒，**这一步最值得看**）

1. 在文献库里点任意一行 → 进「阅读器」；
2. 右栏「论文问答」里问一个**具体数字**的问题，例如
   `这篇论文用了几个注意力头？`（Transformer）或 `GPT-3 有多少参数？`；
3. 看每条结论下面那一行。

**应该看到**：

- 每条结论都带 `p.N`、章节路径、以及一段**英文原文引文**；
- 引文前面有状态：`逐字命中`（绿）/ `模糊匹配`（黄）/ `拦下`（红）；
- 点引文 → 正文跳到那一页那一块，**高亮的就是这几个字**；
- 顶部一行是本次的账：「6 块证据 · 1196 ms · 通过 2 条 · 拦截 0 条」。

**看不到 / 出现别的**：

- 结论没有引文 → 不该发生；有则是回归，请记下来；
- 出现「生成中断（llm）」→ 大模型不可用，这是**降级路径**，此时下面会就地列出召回的原文块，
  系统仍可用（见第 8 步）。

**反例测试**（30 秒，可选）：问一个这篇论文不可能回答的问题，比如「这篇论文的
作者养了几只猫？」。**应该看到**拒答 + 原因，而不是编一段。

## 2. 图表与公式（40 秒）

阅读器右栏切到「**图表公式**」：

- 「表格」段：还原成真表格（行×列），上方标页码与网格尺寸 —— Transformer v7 实测是
  `Table 1 · p.6 · 6×4`、`Table 2 · p.8 · 11×4`；
- 「插图」段：按版面重裁的缩略图 + 图注；
- 「**公式**」段：带编号的公式，`式 (1) · p.4`，图是**从原版面裁的**，
  下面灰底那行是文本层。

**特别看**：BERT / GPT-3 / GPT-4 这几篇的公式段写的是
「没有找到带编号的公式…」——这是**结果**，不是故障。它们本来就没有编号公式。

**为什么第一次要点十几秒**：表格要逐页找网格线（约 0.29 秒/页，前 40 页）。
公式只要 0.01 秒，所以它是**先出来**的，不等表格。

## 3. 版本谱系（30 秒）

左侧导航「版本谱系」→ 选 `Attention Is All You Need` 的 v1 与 v7。

**应该看到**：判定"同一篇的不同版本"、给出 5-gram 重合度、逐段差异与改动分类
（新增 / 删除 / 改写 / 措辞微调），引用数 36 → 40 的变化能逐条点开。

**注意重合度会差很多**：矢量版 v1 ↔ v7 是 **0.68 上下**；但库里的 v1 若是**扫描件**，
OCR 误差会被逐句对齐算成改动，实测只剩 **40.0%**，界面上也会用橙色写清
"旧版是扫描件，条数偏多属正常"。这不是判据坏了，是拿两份不同来源的文本在比。

**看不到**：判成"不同文献" → 阈值或文本抽取出了问题（见 TECH §7.1）。

## 4. 跨文献对比（40 秒）

「跨文献对比」→ A 与 B 各选**两篇不同的**文献（例如 `Language Models are Few-Shot Learners` 与
`Attention Is All You Need · v7`；两栏选了同一篇会提示"请换一篇"）→
问 `BERT 与 Transformer 编码器在预训练目标上有什么不同？`

**应该看到**：同一段回答里，每条结论标注出自哪一篇（`A` / `B` 标签），
点标签能跳到**那一篇**的原文位置（阅读器会自动切文献）。

**看不到标签**：这是 E-038 补的东西，没有则是旧版本。

---

## 5. 检索与「引用含金量」（30 秒）

「文献检索」→ 输入 `attention is all you need` → 检索。

**应该看到**：五个来源各自的状态；每条结果后面带 `被引 N（OpenAlex / Crossref）`；
顶部有「引用含金量」四档门槛与排序下拉。

**注意**：arXiv 与 Zenodo 的接口不提供被引数，它们的条目**不显示**被引 ——
不是 0。筛选到 0 条时有一段说明，而不是空白。

（另：阅读器右栏「参考文献」页顶部有「**导出 BibTeX**」，点了会下载 `.bib`，
可以直接丢进 Zotero / Overleaf。）

## 6. 每日推荐 + 订阅追踪（60 秒）

「每日推荐」→ 上面是推荐列表（每条有"推荐理由"，理由是模板按真实数字拼的）。

滚到下面的「**订阅追踪**」：

1. 在输入框写一个英文关键词（如 `diffusion model`）→ 点「添加追踪」；
2. 等 10–20 秒（要真出网拉 arXiv）。

**应该看到**：一张订阅卡，状态行写「首次抓取，作为基线记下 N 条…不计入新增」，
条目列出标题 + 「首次见到 刚刚」。

**再点一次「立即抓取」**：应该看到「**没有新增**（本轮拿回 40 条，都已见过或与关键词无关）」
—— 这正是"追踪"和"推荐"的区别：它记得自己见过什么。

## 7. 写作 Copilot 的数据可视化（30 秒）

「写作 Copilot」→ 下半部分「数据可视化」→ 点「**用示例数据**」（或上传一份两列 CSV）。

**应该看到**：柱状图 + 一段学术图注，图注下方写「图注中的每个数字均与统计量核对」；
右下角四颗按钮：「导出 SVG + 学术图注」「Mermaid」「TikZ」「Matplotlib」。
四颗都能点，会下载文件。

**特别看**：如果图注里有 `[未核实]`，或下方写着"已整体改用模板图注" ——
那是**核验器拦下了模型编的数字**，不是排版错误。

## 8. 断网 / 无 key 时的样子（30 秒，可选但建议）

停掉 `.env` 里的 `DEEPSEEK_API_KEY` 再起服务（或用手机热点断网打开页面）。

**应该看到**：检索、阅读、图表、公式**照常可用**（前端没有任何外链资源 —— 字体也是
系统栈，所以断网时不会"少一半样式"）；问答返回明确原因
「大模型未配置（缺少 DEEPSEEK_API_KEY）」，并把召回的原文块就地列出来。
**不该看到**：白屏、无限转圈、或一句"出错了"。

## 9. 不该出现的四件事（出现任何一条都是 bug）

| 不该有 | 为什么它是要害 |
|---|---|
| 结论没有出处 | 这个系统全部的卖点就是"每句话能点回原文" |
| 界面上出现 0 被引 / 0 新增却没说明 | 0 是"没有数"，不是"没人引 / 没有新论文" |
| "解析失败"冒充"没有内容" | 让人去查 bug，而其实一切正常 |
| 同一句提示印两遍 | 读者会怀疑这段字是自动生成的（E-044 撞过） |
